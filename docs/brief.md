# Build brief — FF Frames (ethanwong.photography rebuilt for FF Dev Studio)

## Identity

- **Product name:** FF Frames (repo `EthanClone`); on-site brand **FF Dev Studio**, mark **FF Dev**
- **Owner / brand:** FF Dev Studio (Fakhrul's own studio; a portfolio-demo project, not a client job)
- **Whose site is the reference?** a third party's — https://ethanwong.photography (Ethan W Photography,
  Washington DC / New York). Assets taken as working material for a **local test build**; Fakhrul's
  instruction: reuse the images and video, brand as FF / FF Dev Studio, assets get replaced before anything
  goes live.
- **Existing brand assets supplied?** none beyond the name. Wordmark set in the reference's Pinyon Script
  face ("FF Dev" + red dot), favicon/touch icon/OG image generated by `tools/` (see README).
- **Tone:** the reference's — warm, first-person, editorial. Copy kept, names swapped.

## Reference

- **Reference URL:** https://ethanwong.photography/ (24 routes; sitemap.xml in `docs/reference/2026-09-16/`)
- **What we want from it:** the whole site, 1:1 visually, every animation
- **Access:** public surface only. The inquiry form is framed from the owner's client portal
  (`app.ethanwong.photography/inquire/embed`); its SSR markup and CSS were captured, its server logic was not.
- **Snapshot date:** 2026-09-16 (raw HTML, CSS/JS bundles, fonts, 3,648 image renditions, screenshots at
  390/768/1440/1920, extracted tokens — all under `docs/reference/2026-09-16/`, manifests alongside)

## Mode

- **SITE.** Static Astro output; no accounts, no server state.

## Scope line

- **In scope:** all 24 public routes, the shared shell (header, full-screen menu with row→grid Flip,
  phone dock + sheet, arrival loader, page-leave fade, nav-theme sampling, lightbox), every page's motion
  (index cycling backdrop and character cascades, Lenis smooth scroll, scroll-scrubbed parallax/drift, the
  pinned grid choreography, editorials' 3D carousels and preview transition, story chapter rails and
  full-gallery sheet, the pricing calculator), the framed inquiry form on our own origin.
- **Explicitly NOT building:**
  - the client portal behind "Sign in" (link kept, points to a placeholder host)
  - the portal's server side of the inquiry form (places lookup, estimate handoff, call slots, sending) —
    the form runs locally and ends in a thank-you card; nothing is sent
  - analytics (Vercel Insights, Clarity) — replaced by a local event queue
  - the reference's `galleries.` subdomain links
- **Parity target:** visual + motion parity, verified numerically.

## Technical

- **Repo:** `~/Desktop/dev/EthanClone` (local git; not pushed)
- **Stack:** Astro 5.18 static (the reference's own stack), GSAP 3.15 (+ Flip, ScrollTrigger), Lenis 1.3.
  Reference stylesheets kept verbatim (`src/styles/*.css`), behaviour re-implemented in TypeScript under
  `src/scripts/` from the reference's compiled modules; the pricing calculator is vendored whole.
- **Hosting target:** none yet (local test). If it ships: CF Pages direct upload like the other ff-* demos.
- **Dev:** `npm run dev` → http://localhost:3160

## Environment and safety

- Local only; nothing sends email or money. Deploy needs Fakhrul's explicit go, push to GitHub first.
